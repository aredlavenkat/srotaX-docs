    $range

    Generates numbers from an inclusive start to an exclusive end.

    Category: Arrays · Visual function entry: Yes

    Signature (engine metadata)

    Argument syntax: POSITIONAL. Minimum arguments: 2. Maximum: 3.

    Operand Accepted types Required Evaluation
    start INT True EXPRESSION
    end INT True EXPRESSION
    step INT False EXPRESSION

    Result types: ARRAY.

    Null and missing (engine metadata)

    • Null: With start set to literal null in the regression example: throws an exception. This is observed Fluxion behavior, not a general Mongo conformance claim.
    • Missing: With start set to a missing direct-field reference in the regression example: throws an exception. This is observed Fluxion behavior, not a general Mongo conformance claim.

    Compatibility boundary

    Classification: MONGO_6_DIFFERENCES. Verification scope reported by the engine: ENGINE_REGRESSION_EXAMPLES.

    • Fractional ranges are accepted as an extension; Mongo requires integers. Numeric width differs.
    • Verification covers the checked-in regression examples, not full BSON, null, error or collation equivalence.

    These statements come from the engine catalog. This documentation has not independently certified equivalence against a running MongoDB server.
