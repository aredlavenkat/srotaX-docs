# Organize the Catalog

Group assets by business purpose, such as Orders / Shipping, Orders / Fulfillment, and Pricing. Nested folders are supported. **Assets** is the root location.

Open a folder to see its immediate contents, and use breadcrumbs to return to a parent. Workspace search helps locate assets and folders across the hierarchy. Asset identity is an ID; moving an asset does not change its references or executable content.

Create, rename, or move folders inside an editable change set. Only empty folders can be deleted; assets outside the current editing view can still make a folder nonempty. Deletion is also checked by the server.

Untouched folders reflect Main. Your folder edits stay in the selected change set until merged. A folder-only merge changes organization without creating new executable asset versions.
